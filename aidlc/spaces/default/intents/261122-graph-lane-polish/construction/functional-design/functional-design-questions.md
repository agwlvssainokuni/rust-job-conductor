# 機能の設計の質問(Functional Design Questions): graph の text 表示の改善

## Q1. [プロダクト] 「両方の飛び越し」で飛ばされるジョブは、図でどう見えるか

背景: 成功も警告も次のジョブを飛び越す(例: `a` が、成功でも警告でも `c` へ進む)とき、`a` から出る線を描かず、ジョブを `*` の行だけで出す、と決めました。すると、飛ばされるジョブ(`b`)も、ほかのジョブと同じ `*` の行になり、図だけでは、`a` の次が `b` でないことが読み取れません(`-v` を付けると、`a` の下に「成功と警告は `c` へ(`b` を飛び越す)」の注記が出ます)。

設計の見本(`a`、`b`、`c`、`d` の 4 つのジョブで、`a` が両方とも `c` へ進む):

```text
* a
* b
* c
* d
o @end
```

- A. 説明どおり、図は `*` の行だけ。飛び越しは、`-v` の注記だけで分かる
- B. A に加えて、飛ばされるジョブ(`b`)の行の後ろに、注記を付ける(例: `* b  (a が飛び越す)`)。`-v` なしでも分かる
- X. Other (please specify)

[Answer]: A

- A. 全 1,517 例を、テスト用のファイル(`crates/core/tests/fixtures/`)に入れる。今の方式と同じで、取りこぼしがない
- B. ジョブ 7 個以下の 410 例だけを入れる(約 4 万バイト)。ジョブ 8 個の 1,107 例は、入れない
- X. Other (please specify)

[Answer]: A
