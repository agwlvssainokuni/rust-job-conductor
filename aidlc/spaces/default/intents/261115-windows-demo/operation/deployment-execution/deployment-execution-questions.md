背景: この作業が足したのは、`demo/windows/`(デモ)、`demo/README.md`(案内)、`crates/cli/tests/windows_demo.rs`(Windows 専用のテスト)だけである。配布する実行ファイル(`conductor`)のコードは変わっていない。リリース(`release.yml`)はタグ `v*` で動き、タグの版は `crates/cli/Cargo.toml` の版(いま 0.3.0)と一致している必要がある。デモはリリースの配布物には入らない。
