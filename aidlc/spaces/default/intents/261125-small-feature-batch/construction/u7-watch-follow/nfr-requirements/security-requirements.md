# セキュリティの要件: u7-watch-follow

出典: 要件(`requirements.md` の FR7.1〜FR7.5、NFR4、NFR5、NFR6)、機能の仕様(`functional-spec.md` の 2、4、5)、ビジネスルール(`rules.md` の BR1.2、BR2.2、BR4.2)、契約(`contract-summary.md` の C5)、技術スタック(`technology-stack.md`)。

継続表示はステートを読むだけのコマンドである。U6 の流れの直し(BR3.4)はステートに書く時刻を変えない。
