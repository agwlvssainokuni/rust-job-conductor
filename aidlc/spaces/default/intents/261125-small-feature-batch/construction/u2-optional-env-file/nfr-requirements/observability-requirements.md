# 観測の要件: u2-optional-env-file

出典: 要件(`requirements.md` の FR2.2、FR2.5、NFR6)、機能の仕様(`functional-spec.md` の 3、6)、ビジネスルール(`rules.md` の BR2.3、BR3.1)、契約(`contract-summary.md` の C1)、技術スタック(`technology-stack.md`)。
