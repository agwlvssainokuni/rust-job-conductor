# 観測の設計: u2-optional-env-file

出典: 観測の要件(`observability-requirements.md` の NFR1.5、NFR6.4)、技術の選択(`tech-stack-decisions.md`)、機能の仕様(`functional-spec.md` の 3、6)、契約(`contract-summary.md` の C1)。

監視・メトリクス・トレースは当てはまらない。

## 設計

- **飛ばしたことを出さない(NFR1.5)**: `load_env_files` は飛ばした項目を誤りにも警告にも入れず、引き当てにも載せない。表示の層(cli の `report`)は今のまま、受け取ったものだけを出す。`-v` でも出ない。
  - 確かめ方: 実バイナリのテストで、無くてもよいファイルが無いときの標準出力・標準エラーが、そのファイルを書かない定義と同じになることを確かめる。`--dry-run` では、ファイルを置いたときだけその変数の名前が出ることを確かめる。
- **誤りの表示は今のまま(NFR6.4)**: `.env` の誤りの種類・行・ファイル名の表示は変えない。無くてもよいファイルでの誤りも同じ経路で出す。
