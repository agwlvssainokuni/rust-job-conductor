# セキュリティの要件: u4-graph-dot

出典: 要件(`requirements.md` の FR4.3、NFR4、NFR5、NFR6)、機能の仕様(`functional-spec.md` の 3、5)、ビジネスルール(`rules.md` の BR3.1、BR3.2)、契約(`contract-summary.md` の C5)、技術スタック(`technology-stack.md`)。

DOT の出力は、利用者が Graphviz などの別の道具に渡す。守るものは、出力が入力によって壊れたり別の意味を持ったりしないこと(注入)と、ジョブ ID 以外の入力を出さないことである。

## 要件

| ID | 要件 | 合否の基準 | 出典 |
|---|---|---|---|
| NFR6.1 | ラベルは、どのジョブ ID でも DOT の二重引用符の文字列として閉じ、文書の外に出ない(`"`、`\`、改行、制御文字、書式の制御文字を含む ID で、属性や文が増えない) | escape の入力と出力の対の表のテストと、`"`・`\`・改行を含む ID の定義の出力で、引用符の数と行の数が期待どおりになることを確かめる | FR4.3、BR3.1 |
| NFR6.2 | DOT に、ジョブ ID と終点の名前と種類の語のほかの入力の値(コマンド、環境変数、パイプライン名、パス)を書かない。`-v` でも同じ | 目印を入れたコマンド・パイプライン名の定義で、出力に目印が出ないことを確かめる | NFR6、BR3.2、BR2.5 |
| NFR5.1 | `unsafe` と `cfg` を足さない | `nfr_source.rs`(cli) | NFR5 |
| NFR4.1 | 新しい依存を加えない(DOT の整形は自前で書く) | `Cargo.lock` が変わらない | NFR4、team.md の Code Style |
