## Q1. [利用者] 完了後のステートを `watch` が読んだとき、何を表示するか

`watch` は今、ステートの表(パイプライン名、必要なら run ID、ジョブ・状態・補足の 3 列)を出します。完了後もステートを残すと、`watch` が読む `.state` に、全ジョブの結果が入った状態が残ります。依頼では「`no state` ではなく `completed` を表示する(終了コード 0)」と決まっていますが、表を出すかどうかが、決まっていません。

- A. 表をそのまま出し、表の下に、完了を示す 1 行を足す(英語は `completed`、日本語は `完了`。ほかの見出し行と同じく、言語に従う。状態の列の文字は、今までどおり英語固定)
- B. 表は出さず、`completed` の 1 行だけを出す(言語によらず英語)
- C. 表をそのまま出すだけで、完了を示す行は足さない(全ジョブが `success`・`warning`・`skipped` になっていることで、完了が分かる)
- X. Other (please specify)

[Answer]: A
