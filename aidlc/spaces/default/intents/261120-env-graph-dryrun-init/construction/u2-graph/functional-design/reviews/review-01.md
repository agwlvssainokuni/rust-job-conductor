### Summary

The model of edges is consistent with the existing code (forward-only transitions, no error edge, warning mapped with success), and G1-G9 are faithful git output, but the design is not yet implementable as written: `--state` would show a completed run as all pending, and the layout rules plus nine examples do not determine the output (including a glyph, `_`, outside the allowed set) for three overlapping skips, mixed skip targets, or label and node-row alignment, which a developer would have to guess without copying git's source.
