# 外部の依存の地図(External Dependency Map): v0.9.0 の機能拡張

この文書は、チームの外にあって、作業を止めうるもの(外部の API、データ、承認、ほかのチームからの引き渡し)を、それを使う Bolt(作りの 1 回のまとまり)に対応づけて記します。

出典: `bolt-plan.md`、チームの慣行(`practices-discovery/team-practices.md`)、納品計画の質問(`delivery-planning-questions.md` の Q5: A)。

## 1. 結論

作業を止める、チームの外のものは、ない(Q5: A)。4 つの Bolt のすべてが、このリポジトリの中で完結する。

| 項目 | 持ち主 | 待つ時間 | 止まる Bolt | 遅れたときの対応 |
|------|--------|----------|--------------|--------------------|
| 外部の API | なし | なし | なし | 該当なし |
| 外部のデータ | なし | なし | なし | 該当なし |
| 承認の待ち(チームの外) | なし | なし | なし | 該当なし |
| ほかのチームからの引き渡し | なし | なし | なし | 該当なし |

## 2. 補足(外部のサービスだが、待ちではないもの)

- **CI(GitHub Actions)**: マージの前に、`test`(ubuntu、macos、windows)、`lint`、`coverage`、`build-check`、`msrv-test` などが走る。作業を止めるのではなく、確認の手段である。CI の失敗は、その Bolt の中で直す。
- **新しい外部ライブラリ**: 足さない(`project.md`)。`.env` の読み込みとグラフの描画は、自前で書く。そのため、依存の取得や、ライブラリの更新の待ちはない。
- **リリース(タグ、下書きのリリースの公開)**: この作業の範囲の外(別の依頼)。
