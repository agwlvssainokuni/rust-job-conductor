# Requirements Analysis — 確認事項

意図の整理と範囲の定義で決めたこと: ジョブごとに、リトライする終了コード、最大回数 N、間隔(固定、回ごとに伸ばす方式)を書ける。途中の様子を表示する。設定しない定義ファイルは今までと同じ動作。出力の内容での判定と、外部への通知はやらない。

現状の定義には、ジョブごとに `success_exit_codes`(成功)と `warning_exit_codes`(警告)があり、どちらにも入らない終了コードが「エラー」になります。
