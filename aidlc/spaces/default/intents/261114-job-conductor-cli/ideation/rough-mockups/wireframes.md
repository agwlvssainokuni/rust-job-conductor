# Wireframes(コマンド入出力のイメージ)

上流: intent-statement(課題・利用者)、scope-document(初版の機能)、intent-backlog(暫定ユニット)。

`conductor` は画面を持たないコマンドラインツールであり、Web UI / GUI は初版の対象外である(scope-document の Out of Scope)。そのため、ここでは画面ではなく、システム間のやり取りと、コマンドごとの入出力イメージを描く。以下の表示文言や名称は**イメージ**であり、確定した仕様ではない。

## 1. システム全体のやり取り(個別実行)

最優先の利用場面は、既存スケジューラから `conductor run <job-id>` が1ステップずつ呼ばれる場面である。 [Q1]

```
+----------------+   conductor run <job-id>   +-----------+   ジョブのコマンド   +--------+
| 既存の         | -------------------------> | conductor | ------------------> | ジョブ |
| ジョブスケジューラ | <------------------------- |           | <------------------ | 本体   |
+----------------+     終了コード 0 / 非0      +-----------+    終了コード/出力   +--------+
                                                   |  ^
                                         状態の書込み |  | 状態の参照
                                                   v  |
                                              +--------------+
                                              | ステート      |
                                              | ファイル(ローカル)|
                                              +--------------+
```

- スケジューラが受け取る終了コードは 0 / 非0 の2値のみである。 constraint-register の C2
- 状態はローカルのステートファイルに保持する。 intent-backlog の「定義ファイルとステート管理」

## 2. コマンド別の入出力イメージ

### 2.1 `conductor run <job-id>`(個別実行)

```
$ conductor run transform
(ジョブ本体の標準出力・標準エラーがそのまま流れる)
$ echo $?
0
```

- `conductor` 自身の表示は、オプションで有効にしない限り出さない。ジョブ本体の出力をそのまま通す。 [Q2]
- 後続ジョブがスキップ対象だった場合も、何も表示せず終了コード 0 で終わる。表示は、オプションで有効にしたときだけ出す。 [Q3]
- 定義ファイルの誤りなど、`conductor` 自身のエラーは、この「表示なし」の対象外とし、常に表示する(2.3 参照)。 [Q5, 承認時の依頼者の指示]

### 2.2 `conductor watch`(状態の確認)

```
$ conductor watch
ジョブ        状態
extract       警告
transform     成功
load          スキップ
```

- 現在の状態を一覧で1回表示して終了する。変更を追って表示し続けることはしない。 [Q4]
- 状態は色だけでなく文字(成功 / 警告 / スキップ / 失敗)でも分かるようにする。端末以外への出力では色を自動で無効にする。 [Q6]
- 上の表示の文言・列、および4つの状態名(成功 / 警告 / スキップ / 失敗)は、確認の仕方を示すイメージであり、確定した仕様ではない。

### 2.3 定義ファイルに誤りがあるとき

```
$ conductor run transform
エラー: <定義ファイル名>:<行>: <原因の説明>
$ echo $?
(非0)
```

- ジョブを一切実行せず、原因(ファイル名・行・内容)を表示して異常終了する。 [Q5]
- このエラー表示は、表示を有効にするオプションの有無にかかわらず常に出す。 [Q5, 承認時の依頼者の指示]
- スケジューラに返る終了コードは 0 / 非0 の2値のみである。 constraint-register の C2

## 3. 補助的なコマンド

- `conductor pipeline <pipeline-name>`(一連の実行)、`conductor reset`(状態の初期化)、`conductor convert <file> --to <format>`(YAML ⇔ TOML 変換)は、初版に含めるがこの段階では表示のイメージを描かない。個別実行を優先するため。 [Q1]

## Assumptions & Open Questions

- 「`conductor` 自身の表示を有効にするオプション」の名称・粒度(ジョブ結果とスキップ表示を同じオプションで有効にするか)は未決定であり、後続のステージで決める。 [Q2, Q3]
- 一連の実行(pipeline)の入出力イメージは、個別実行を優先したため未作成であり、後続のステージで扱う。 [Q1]
