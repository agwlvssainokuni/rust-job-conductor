# 性能のテストの手順(Performance Test Instructions): graph の配置のリファクタリング

## コマンド

```bash
cargo test --locked -p conductor-core --test graph_perf
```

## 内容

- 1,000 ジョブの図を、1 秒以内に作ること(既存の通常の飛び越し、交差、同じ行き先の形に加え、今回「両方の飛び越し」と分岐を含む 1,000 ジョブの 2 本を足した)。
- 計算量: 実行されうるジョブの判定は、辺の数に比例する。寄せの重複探しは線の数に比例し、寄せの回数は作った線の数以下なので、全体は高々 2 乗。
- 起動の性能(`nfr_perf.rs`、CI の `startup-bench`)は、警告のみで、この変更で変わらない。

## 限界

- 1,000 ジョブのテストは、時間だけを確かめる(図の正しさは、ジョブ 7 個以下の正解データで確かめる)。
